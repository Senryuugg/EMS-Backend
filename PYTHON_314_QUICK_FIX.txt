PYTHON 3.14 ISSUE - QUICK FIX
=============================

PROBLEM:
--------
You are using Python 3.14 (very new!)
pydantic-core has NO pre-built wheels for Python 3.14 yet
It tries to compile from source but fails (missing C++ linker)

Error: "linker `link.exe` not found"

SOLUTION (RECOMMENDED - 5 minutes):
-----------------------------------
Downgrade to Python 3.12 or 3.13

STEP 1: Uninstall Python 3.14
1. Open Settings > Apps > Apps & features
2. Find "Python 3.14"
3. Click and select "Uninstall"
4. Complete uninstallation

STEP 2: Install Python 3.12
1. Go to https://www.python.org/downloads/
2. Download "Python 3.12.x" (latest 3.12 version)
3. Run installer
4. IMPORTANT: Check "Add Python to PATH"
5. Click "Install Now"

STEP 3: Verify Installation
Open new Command Prompt and run:
  python --version

You should see: Python 3.12.x

STEP 4: Create New Virtual Environment
cd D:\EMS-Dispatcher-Application
python -m venv venv
venv\Scripts\activate

STEP 5: Install Dependencies
pip install --upgrade pip
pip install -r requirements.txt

SUCCESS: You should see all packages installing without errors!

ALTERNATIVE (For Advanced Users):
----------------------------------
If you MUST use Python 3.14, install Visual Studio Build Tools:

1. Download: https://visualstudio.microsoft.com/downloads/
2. Find "Build Tools for Visual Studio 2022"
3. Click "Download"
4. Run installer
5. Select "Desktop development with C++"
6. Complete installation (~4 GB)
7. Restart computer
8. Try pip install again

This takes ~30 minutes but will work.

QUICK REFERENCE:
----------------
Python 3.14: NEW - NO wheel support yet - NOT recommended
Python 3.13: Stable - Full support - GOOD choice
Python 3.12: Stable - Full support - BEST choice (recommended)
Python 3.11: Stable - Full support - WORKS fine

DECISION:
---------
EASIEST: Install Python 3.12 (5 minutes, 100% success)
HARDEST: Build Tools for Visual Studio (30 minutes, works for 3.14)

We recommend Python 3.12.
