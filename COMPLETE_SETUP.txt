EMS DISPATCHER - COMPLETE SETUP GUIDE
=====================================

Your situation: Python 3.11 to 3.14 installed
Goal: Use Python 3.12 for the project
Status: Ready to install!

STEP 1: SELECT PYTHON 3.12
==========================

Open Command Prompt (Windows key + R, type cmd):

1.1 Check all Python versions installed:
    py --list-paths

    You'll see output like:
    -3.14 C:\Python314\python.exe (or similar)
    -3.12 C:\Python312\python.exe
    -3.11 C:\Python311\python.exe

    (Find the -3.12 line)

1.2 Navigate to project folder:
    cd D:\EMS-Dispatcher-Application

1.3 Create virtual environment with Python 3.12:
    py -3.12 -m venv venv

    (This takes 10-15 seconds)

1.4 Activate the virtual environment:
    venv\Scripts\activate

    (You should see "(venv)" at start of command line)

1.5 Verify Python 3.12 is active:
    python --version

    (Should show: Python 3.12.x)


STEP 2: INSTALL PYTHON PACKAGES
================================

2.1 Clear pip cache (important!):
    pip cache purge

2.2 Upgrade pip itself:
    python -m pip install --upgrade pip

2.3 Install project requirements:
    pip install -r requirements.txt

    (This takes 2-5 minutes)

2.4 Verify installation:
    pip list | findstr fastapi

    (Should show fastapi in the list)


STEP 3: TEST ML SERVICE
=======================

3.1 Start the ML API:
    python ml_api.py

    (You should see: Uvicorn running on http://127.0.0.1:8000)

3.2 In browser or new terminal, test it:
    curl http://localhost:8000/health

    (Should return: {"status":"healthy"})


STEP 4: RUN BACKEND API (New Command Prompt)
=============================================

4.1 Open NEW Command Prompt window

4.2 Navigate to backend:
    cd D:\EMS-Dispatcher-Application\EmsDispatch.Backend

4.3 Start backend:
    dotnet run

    (Should start on http://localhost:5000)


STEP 5: DOCKER SERVICES (New Command Prompt)
=============================================

5.1 Open NEW Command Prompt window

5.2 Start Docker services:

5.3 Check if running:

5.4 View MongoDB data:
    http://localhost:8081
    (Login: admin / password)

IF SOMETHING FAILS
==================

Error: "py" not found
→ Solution: Python launcher not installed
→ Run: python -m venv venv (without py -3.12)
→ Then check: python --version

Error: Building wheel for pydantic-core
→ Solution: Using wrong Python version
→ Delete venv folder
→ Start over from Step 1.3

Error: pip install fails
→ Solution: Python version mismatch
→ Run: pip cache purge
→ Run: pip install --upgrade pip
→ Try again: pip install -r requirements.txt --no-cache-dir

Error: ModuleNotFoundError
→ Solution: Packages not installed
→ Check: pip list
→ Reinstall: pip install -r requirements.txt


DEACTIVATE VIRTUAL ENVIRONMENT
==============================

When done working:
  deactivate

(You'll see "(venv)" disappear from prompt)

To use again:
  venv\Scripts\activate


SUMMARY
=======

Windows Python launcher (py command) makes it easy to use specific Python versions:

py --list-paths          → See all versions
py -3.12 -m venv venv    → Create venv with Python 3.12
venv\Scripts\activate    → Use the venv
pip install -r requirements.txt → Install packages

Everything else works normally!
