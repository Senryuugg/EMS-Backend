EXACT COMMANDS TO RUN AFTER DOWNGRADING TO PYTHON 3.12
======================================================

After you install Python 3.12, open NEW Command Prompt and run:

Step 1: Navigate to project
  cd D:\EMS-Dispatcher-Application

Step 2: Delete old venv
  rmdir /s venv
  (Type Y and press Enter when asked)

Step 3: Create new venv
  python -m venv venv

Step 4: Activate venv
  venv\Scripts\activate
  (You should see (venv) at the start of the prompt)

Step 5: Upgrade pip
  python -m pip install --upgrade pip

Step 6: Install requirements
  pip install -r requirements.txt

Step 7: Test installation
  python -c "import fastapi; import pandas; import numpy; print('SUCCESS!')"

If you see "SUCCESS!" - You're done!

Step 8: Start ML API (to verify)
  python ml_api.py

If you see "Uvicorn running on http://127.0.0.1:8000" - Perfect!
