PYTHON 3.12 SELECTION - CHEAT SHEET
===================================

Your Situation:
- Python 3.11, 3.12, 3.13, 3.14 all installed on Windows
- Need to use Python 3.12
- Don't know how

SOLUTION: Use Python Launcher (py command)
==========================================

COMMAND 1: Check versions
  py --list-paths

OUTPUT example:
  -3.14 C:\Python314\python.exe
  -3.12 C:\Python312\python.exe    ← This is what you need
  -3.11 C:\Python311\python.exe


COMMAND 2: Create environment with Python 3.12
  py -3.12 -m venv venv

(Creates a folder called "venv" with Python 3.12)


COMMAND 3: Activate environment
  venv\Scripts\activate

(You'll see "(venv)" appear in command prompt)


COMMAND 4: Verify Python 3.12 is active
  python --version

OUTPUT: Python 3.12.x (not 3.13 or 3.14)


COMMAND 5: Install packages
  pip install -r requirements.txt

(Now it installs for Python 3.12!)


COMMAND 6: Test it works
  python ml_api.py

(Should start without build errors)


IF "py" DOESN'T WORK:
====================

Try this instead:

  python -m venv venv
  venv\Scripts\activate
  python --version

(If it shows 3.14 instead of 3.12, delete venv and repeat)


ALL COMMANDS IN ONE BLOCK:
==========================

Open Command Prompt and copy-paste this:

cd D:\EMS-Dispatcher-Application
py --list-paths
py -3.12 -m venv venv
venv\Scripts\activate
python --version
pip install -r requirements.txt
python ml_api.py


WHAT EACH COMMAND DOES:
=======================

cd D:\... → Navigate to project
py --list-paths → Show all Python versions
py -3.12 → Tell it to use Python 3.12
-m venv → Python module for environments
venv → Name of folder (can be anything)
venv\Scripts\activate → Run Python 3.12 from venv
python --version → Check which Python is active
pip install → Install packages using this Python
python ml_api.py → Run the ML service


KEY POINT:
==========

When you're inside (venv), all Python commands use
the Python 3.12 version inside venv folder.

When you're NOT in (venv), it uses system default
(might be 3.14 or any other version).

That's why the "(venv)" in your prompt matters!


WINDOWS PYTHON LAUNCHER SYNTAX:
================================

py --version              Show default Python
py --list-paths           List all versions
py -3.12                  Run Python 3.12
py -3.12 script.py        Run script with Python 3.12
py -3.12 -m venv venv     Create venv with Python 3.12


DONE!
=====

Once you see "(venv)" in prompt and "python --version"
shows "Python 3.12.x", you're using Python 3.12!

Then just: pip install -r requirements.txt

All packages will install for Python 3.12 without errors.
