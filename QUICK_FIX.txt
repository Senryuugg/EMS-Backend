QUICK FIX FOR PIP INSTALL ERROR
=================================

YOUR ERROR: "Unknown compiler(s)" - NumPy/Pandas building from source failed

FASTEST FIX (2 MINUTES):
========================
1. Open Command Prompt
2. Navigate to your project
3. Run these 3 commands:

   venv\Scripts\activate
   python -m pip install --upgrade pip
   pip install -r requirements.txt

That's it! Modern pip has pre-built wheels.


IF THAT DOESN'T WORK (5 MORE MINUTES):
======================================
   pip cache purge
   pip install --upgrade setuptools wheel
   pip install -r requirements.txt


STILL NOT WORKING? (15 MINUTES):
================================
Switch to Python 3.11 (pre-built wheels guaranteed)
- Uninstall Python 3.12
- Download Python 3.11 from python.org
- Check "Add to PATH"
- Delete venv folder
- Create new venv and reinstall


YOU'VE UPDATED requirements.txt:
================================
Old: Specific versions (pandas==2.1.4, numpy==1.26.4)
New: Flexible versions (pandas>=2.0.0, numpy>=1.24.0)

This lets pip choose compatible pre-built wheels!
