PIP INSTALL TROUBLESHOOTING FOR NUMPY/PANDAS
==============================================

WHAT WENT WRONG
================
Your error message showed:
- "Unknown compiler(s)" 
- NumPy trying to build from source
- No C compiler found on Windows

ROOT CAUSE
===========
You're using Python 3.12 + Windows + old pip version
Result: Pip tries to build NumPy from source instead of using pre-built wheels


THE FIX (EASIEST - 2 MINUTES)
=============================

Step 1: Update pip to latest version
   python -m pip install --upgrade pip

Step 2: Clear pip cache 
   pip cache purge

Step 3: Install requirements again
   pip install -r requirements.txt

WHY THIS WORKS:
- New pip versions have better wheel compatibility
- NumPy 1.24+ and Pandas 2.0+ have Python 3.12 wheels
- requirements.txt now uses flexible versions (>=) not fixed (==)


BACKUP PLANS IF THAT FAILS
============================

Plan A: Install more tools (5 min)
---------------------------------
pip install --upgrade setuptools wheel
pip cache purge
pip install -r requirements.txt

Plan B: Use Python 3.11 instead (15 min)
----------------------------------------
1. Uninstall Python 3.12
2. Install Python 3.11
3. Create new virtual environment
4. pip install -r requirements.txt

(Python 3.11 has more compatible pre-built wheels)

Plan C: Install Visual C++ Build Tools (30 min)
---------------------------------------------
Download from: https://visualstudio.microsoft.com/downloads/
Select: "Desktop development with C++"
Then: pip install -r requirements.txt

(Allows compilation from source if no wheels available)


WHAT CHANGED IN requirements.txt
=================================

BEFORE (causes issues):
  pandas==2.1.4
  numpy==1.26.4
  scikit-learn==1.3.2

AFTER (more flexible):
  pandas>=2.0.0
  numpy>=1.24.0
  scikit-learn>=1.3.0

This lets pip choose compatible pre-built wheels automatically.


VERIFY IT WORKED
=================

Run this to test:
python -c "import pandas, numpy, sklearn; print('Success!')"

You should see: Success!


DETAILED ERROR BREAKDOWN
=========================

Your error shows:
- Failed to activate VS environment (Visual Studio not installed)
- Meson build system looking for compilers (cl, gcc, clang, etc.)
- None of the compilers found

This is Windows-specific because:
- Windows doesn't come with a C compiler by default
- Linux/Mac have gcc/clang pre-installed
- NumPy/Pandas need C compiler OR pre-built wheels


THE BEST SOLUTION
==================

1. Try updating pip first (90% success rate) - 2 min
2. If that fails, use Python 3.11 (99% success rate) - 15 min
3. Only install Build Tools as last resort - 30 min

Start with option 1. Most likely to work fastest.
