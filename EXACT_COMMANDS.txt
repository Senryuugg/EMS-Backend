COPY & PASTE THESE EXACT COMMANDS
=================================

Navigate to project folder first:
  cd D:\EMS-Dispatcher-Application

Then copy and paste these commands one by one:


COMMAND 1: Activate Virtual Environment
========================================
venv\Scripts\activate

(Should show (venv) before your command prompt)


COMMAND 2: Upgrade Pip
======================
python -m pip install --upgrade pip

(Watch for: Successfully installed pip-XX.X.X)


COMMAND 3: Clear Cache
======================
pip cache purge

(Just press Enter, cache will be cleared)


COMMAND 4: Install Requirements
================================
pip install -r requirements.txt

(This should now work without errors!)
(Watch for: Successfully installed [packages])


TEST COMMAND: Verify Installation
==================================
python -c "import pandas; import numpy; import sklearn; print('SUCCESS!')"

(Should print: SUCCESS!)


IF COMMAND 4 FAILS
==================

Try these two additional commands:

pip install --upgrade setuptools wheel
pip cache purge
pip install -r requirements.txt


IF THAT STILL FAILS
===================

See: STEP_BY_STEP_FIX.txt for Plan B & C


WINDOWS COMMAND PROMPT TIPS
============================

- Don't include the comment parts (#...)
- Copy the command exactly
- Press Enter after each command
- Wait for it to complete before next command
- If you see an error, don't run the next command
