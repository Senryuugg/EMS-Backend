COMPLETE GUIDE TO FIX YOUR PYTHON 3.14 ERROR
=============================================

YOUR ERROR ANALYSIS:
-------------------
Python Version: 3.14 (brand new - just released)
Problem: pydantic-core needs to compile from Rust source
Missing: Visual C++ Build Tools / linker (link.exe)

Why? Python 3.14 pre-built wheels don't exist yet for pydantic-core!

SOLUTION #1: DOWNGRADE PYTHON (EASIEST - RECOMMENDED)
====================================================

Step 1: Close all terminals and VS Code

Step 2: Uninstall Python 3.14
- Press Windows key + I (Settings)
- Go to Apps > Apps & features
- Find "Python 3.14"
- Click it and select "Uninstall"
- Follow the uninstaller

Step 3: Install Python 3.12
- Open browser: https://www.python.org/downloads/
- Click on "Python 3.12.X" (latest 3.12 version)
- Download the installer
- Run the installer
- CRITICAL: Check the box "Add Python to PATH"
- Click "Install Now"
- Wait for installation to complete

Step 4: Verify Installation
- Open NEW Command Prompt (Win+R, type cmd, Enter)
- Type: python --version
- You should see: Python 3.12.X

Step 5: Delete old virtual environment
- Open Command Prompt
- cd D:\EMS-Dispatcher-Application
- rmdir /s venv
- Type Y and press Enter

Step 6: Create new virtual environment
- cd D:\EMS-Dispatcher-Application
- python -m venv venv
- Wait for it to complete

Step 7: Activate virtual environment
- venv\Scripts\activate
- You should see (venv) at start of prompt

Step 8: Install dependencies
- pip install --upgrade pip
- pip install -r requirements.txt
- Should complete WITHOUT errors!

SOLUTION #2: INSTALL BUILD TOOLS (ADVANCED)
============================================

If you MUST keep Python 3.14:

Step 1: Download Visual Studio Build Tools
- Go to: https://visualstudio.microsoft.com/downloads/
- Scroll down to "Build Tools for Visual Studio 2022"
- Click "Download"

Step 2: Run the installer
- Run the downloaded file
- Click "Continue"

Step 3: Select C++ Development
- Check "Desktop development with C++"
- This is ~4 GB, will take time
- Click "Install"

Step 4: Restart computer
- After installation completes
- Restart your computer

Step 5: Retry pip install
- Open new Command Prompt
- cd D:\EMS-Dispatcher-Application
- venv\Scripts\activate
- pip install --upgrade pip
- pip install -r requirements.txt

TROUBLESHOOTING:
----------------

If you still get errors after Python 3.12:
1. Delete venv folder: rmdir /s venv
2. Create new venv: python -m venv venv
3. Activate: venv\Scripts\activate
4. Clear pip cache: pip cache purge
5. Try again: pip install -r requirements.txt

If you see "Python is not recognized":
1. Close ALL terminals and VS Code
2. Open NEW Command Prompt
3. Type: python --version
4. If still error, Python not in PATH
5. Reinstall Python and check "Add to PATH"

WHICH SOLUTION TO CHOOSE:
-------------------------

Choose Solution #1 (Downgrade to Python 3.12):
- Takes 5-10 minutes
- 100% guaranteed to work
- RECOMMENDED!

Choose Solution #2 (Install Build Tools):
- Takes 30-45 minutes
