STEP BY STEP FIX FOR PIP INSTALL ERROR
======================================

STEP 1: ACTIVATE VIRTUAL ENVIRONMENT (30 seconds)
=================================================

Windows Command Prompt:
  cd D:\EMS-Dispatcher-Application
  venv\Scripts\activate

(You should see: (venv) in your command prompt)

Windows PowerShell:
  cd D:\EMS-Dispatcher-Application
  .\venv\Scripts\Activate.ps1

(You should see: (venv) before your prompt)


STEP 2: UPDATE PIP (30 seconds)
==============================

Type this command:
  python -m pip install --upgrade pip

You'll see messages like:
  Collecting pip
  Downloading pip-XX.X.X-py3-none-any.whl
  Installing collected packages: pip
  Successfully installed pip-XX.X.X

(Your pip version number will be different)


STEP 3: CLEAR PIP CACHE (15 seconds)
===================================

Type:
  pip cache purge

You'll see message:
  Removed X files


STEP 4: INSTALL REQUIREMENTS (2-5 minutes)
=========================================

Type:
  pip install -r requirements.txt

You should see:
  Collecting fastapi==0.104.1
  Collecting uvicorn==0.24.0
  ... (more packages)
  Successfully installed [list of packages]

NO ERROR means SUCCESS!


IF YOU GET AN ERROR AT STEP 4
=============================

Try this:
  pip install --upgrade setuptools wheel
  pip cache purge
  pip install -r requirements.txt


IF THAT ALSO FAILS
==================

Switch to Python 3.11:

1. Uninstall Python 3.12:
   - Go to: Settings > Apps > Apps & features
   - Find: Python 3.12
   - Click: Uninstall

2. Install Python 3.11:
   - Go to: python.org
   - Download: Python 3.11 latest version
   - Run installer
   - CHECK: "Add Python 3.11 to PATH"
   - Click: Install Now
   - Click: Disable path length limit (if prompted)

3. Delete old virtual environment:
   - Open Command Prompt in project folder
   - Type: rmdir /s venv
   - Type: y (confirm deletion)

4. Create new virtual environment:
   - Type: python -m venv venv
   - Type: venv\Scripts\activate
   - Type: python -m pip install --upgrade pip

5. Install requirements:
   - Type: pip install -r requirements.txt


VERIFY INSTALLATION WORKED
==========================

Type:
  python -c "import pandas; import numpy; import sklearn; print('All packages installed successfully!')"

If you see:
  All packages installed successfully!

Then you're good to go!


STILL HAVING ISSUES?
====================

Run this diagnostic command:
  python -m pip --version
  python --version
  pip install --upgrade setuptools wheel

Then try:
  pip install -r requirements.txt --verbose

The --verbose flag shows exactly what's happening.


WHAT EACH STEP DOES
===================

Step 1: Activates virtual environment
  - Ensures pip installs in right location
  - Keeps your system Python clean

Step 2: Updates pip itself
  - New pip knows about pre-built wheels
  - Better compatibility with Python 3.12

Step 3: Clears old cached information
  - Removes old cached packages
  - Forces pip to fetch fresh data

Step 4: Installs all packages
  - Should now find pre-built wheels
  - Shouldn't try to compile NumPy

TOTAL TIME: 5-10 minutes
