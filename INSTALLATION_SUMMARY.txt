================================================================================
                        COMMON ISSUES & FIXES
================================================================================

ISSUE 1: "Failed to build 'pandas'"
FIX:
  1. Use Python 3.11 instead of 3.12
  2. Or install Visual Studio Build Tools
  See: WINDOWS_INSTALLATION_FIX.md

ISSUE 2: "Python not found"
FIX:
  1. Reinstall Python 3.11
  2. Make sure "Add to PATH" is checked
  3. Restart Command Prompt

ISSUE 3: "Docker not running"
FIX:
  1. Start Docker Desktop
  2. Wait 1-2 minutes to load
  3. Try again

ISSUE 4: ".NET build failed"
FIX:
  1. Run: dotnet clean
  2. Run: dotnet restore
  3. Run: dotnet build

ISSUE 5: "Port 5000 already in use"
FIX:
  1. Stop other services using port 5000
  2. Or change port in appsettings.json

================================================================================
                        IMPORTANT REMINDERS
================================================================================

1. USE PYTHON 3.11 (NOT 3.12)
   - Python 3.12 needs Build Tools or has package issues
   - Python 3.11 has better pre-built wheels

2. ACTIVATE VIRTUAL ENVIRONMENT
   - Always run: venv\Scripts\activate
   - Should see (venv) in command prompt

3. KEEP DOCKER RUNNING
   - Docker Desktop must stay open while developing
   - Services run in Docker containers

4. UPDATE PIP FIRST
   - Always run: python -m pip install --upgrade pip
   - Old pip versions cause installation issues

5. RESTART TERMINAL AFTER INSTALLING PYTHON
   - New Python installations need terminal restart
   - PATH changes don't take effect until restart
